# 目标

## 一句话

把可执行制品恢复成**可证明与它等价、并且可维护**的源码。

不是"复刻一份看起来像的代码"，也不是"能编译就行"。等价性要能被证明，可维护性要能被约束——
两者都有可检验的标准，而不是靠谁说"我看过觉得对"。

## 两个终点

| 终点 | 判据 | 谁来检查 |
| --- | --- | --- |
| **等价** | 下面的分档判据 | 脚本，不依赖人的判断 |
| **可维护** | 人能读懂、能改；`docs/` 只放当前状态 | 人 |

"等价"必须由脚本给出结论。

## 验收分档

不是所有类都值得花同样的代价。分档依据只有一条：

> **这里出错，会不会看起来像是对的？**

| 档 | 什么时候进这一档 | 判据 |
| --- | --- | --- |
| **严格** | 坏了不报错，只是悄悄给出错误结果，且输入空间不可枚举 | 方法级字节码等价 |
| **宽松** | 坏了会大声坏：抛异常、起不来、数据明显不对、没有输出 | ABI 一致 + 冒烟 |
| **划出** | 行为另行定义（许可证的激活语义，密钥将重置） | 只验路由接线存在 |

典型归属：

- **严格**：书源规则引擎（`model.analyzeRule`）、`model.webBook`、`model.rss`、`model.localBook`、
  `help.SourceAnalyzer`、`help.JsExtensions`、`help.http`、编码相关（`BytesEncodingDetect`、
  `EncodingDetect`、`EncoderUtils`、`StringExtensionsKt`、`HtmlFormatter`）
- **宽松**：`data.entities` 的 data class、数据库、配置、TTS、适配器、`verticle`、`utils` 其余
- **划出**：许可证激活行为

分界不看包，看**它是否处在一条会静默出错的数据通路上**。

## 判据

| 判据 | 覆盖 | 不覆盖 |
| --- | --- | --- |
| ABI（`javap -p -s`） | 成员、类型、修饰符、泛型签名、继承关系 | 方法体 |
| 字符串常量逐字比对 | 常量池里的值（正则、模板字符串） | 控制流、分支、参数顺序 |
| 方法级字节码等价 | 指令序列、调用目标、分支结构 | 需归一化编译器版本差异 |
| 行为差分 | 端到端语义 | 没探到的路径 |

前三个是静态闸门，**每一片必跑**；行为差分是动态兜底。

### 字节码等价有个工具链前提

"方法级字节码等价"能成立，是因为制品与重建都在同一条 Kotlin 1.5 线上编译。这只对
**Kotlin 来源**的类成立。

**Java 来源**的类（反编译产物里没有 `@Metadata` 的那些）由另一套 javac 编译过，
指令序列会因编译器版本产生合法噪声，压不到零差异。这一小部分降级为
**ABI + 字符串常量 + 行为差分**，并在索引里标出。

严格档 58 个顶层类里有 5 个属于这种情况：`help.BytesEncodingDetect`、`help.Encoding`、
`help.EncodingDetectHelp`、`model.analyzeRule.QueryTTF`、`utils.TextUtils`。

## 三个阶段

顺序不能换。

1. **严格还原** —— 目标：与制品等价。
   闸门：静态判据全过。
2. **建行为差分** —— 目标：让第三阶段的改动有判据。
   闸门：覆盖所有只读路由 + 规则引擎的代表性输入。
3. **结构重构** —— 目标：让人能改。
   闸门：行为差分通过。

第 1 步不做，第 3 步无从判断对错；第 2 步不做，第 3 步没有判据。

## 书写纪律

第一阶段就应拿到的可读性（免费，不影响字节码）：

- 局部变量名、参数名取自制品——**制品保留了原始名**，用 `javap -l` 取
- 每个类一行说明它做什么
- 注释与格式

第一阶段**不能做**的（会破坏等价）：

- 抽方法、合并分支、换数据结构
- 改写 `runCatching {}` / `try-catch` 的形态
- 删掉"看起来没用"的 `bl = false;`——那是内联函数留下的标记

## 降级规则

少数类可能达不到零差异（`BookController` 11,622 行、`YueduApi` 7,884 行这类协程密集文件）。
达不到时降级为"ABI 一致 + 行为差分通过"，并在索引里标出。

**不允许因为个别类把整个项目卡住。** 这与"不加区分地花严格预算"是同一类错误的两个方向。

## 索引

每个类一行：`类名 | 档位 | 状态 | 判据结果`。

两个用途：

- 让"完成到哪"不依赖任何人的口报
- 让第三阶段不必把代码读第二遍

索引由脚本从制品与本仓库的类集合差集生成，不手工维护。

## 明确不做

- 重建原始 Gradle 文件——它们不在制品里。本仓库的构建依据制品的依赖集合写成，并如实标注
- 制品字节码或资源触及范围之外的行为
- 为了"统一风格"批量重构
- 把历史堆进 `docs/`——历史属于 git log 与提交信息
